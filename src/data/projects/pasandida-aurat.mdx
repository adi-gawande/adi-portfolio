# Animated Portfolio Website

## Overview

This animated portfolio website is built to **showcase projects, skills, and experience** in an engaging and interactive way.  
It focuses on **motion-driven UI**, smooth transitions, and clean design to create a memorable user experience.

## What Users Can See

- 🎨 Animated hero section and page transitions
- 🧩 Interactive project showcase
- 💼 Skills and experience sections
- 🧠 About me section with storytelling
- 📱 Fully responsive design
- ⚡ Smooth scrolling and micro-interactions
