# StudyNotion: Online Education Platform

## Overview

StudyNotion is a full-stack ed-tech platform that enables **students to learn**, **instructors to teach**, and **admins to manage the ecosystem**.  
It provides a seamless experience for course creation, enrollment, payments, and content consumption.

---

## What Users Can Do

### 👨‍🎓 Students

- Browse and purchase courses
- Watch video lectures and access course materials
- Add courses to wishlist & cart
- Rate and review courses
- Manage personal profile

### 👨‍🏫 Instructors

- Create, update, and delete courses
- Upload videos and course content
- Track course performance & student engagement
- Manage pricing and published content

### 🛠 Admin (Future Scope)

- Monitor platform statistics
- Manage instructors & courses
- View revenue and user growth analytics

---

## Why I Built This

I built **StudyNotion** to understand how **real-world ed-tech platforms** work end-to-end:

- How learning platforms scale with multiple user roles
- How instructors manage content independently
- How secure payments and enrollments work
- How to design a complete MERN architecture
- How to handle real-world authentication & authorization

This project helped me bridge the gap between **tutorial apps** and **production-grade systems**.

---

## Tech Stack

### Frontend

- React.js
- Tailwind CSS
- Redux for state management

### Backend

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Bcrypt for password hashing

### Integrations

- Razorpay Payment Gateway
- Cloudinary for media storage

---

## System Architecture

- **Client-Server Architecture**
- React frontend communicates with backend via REST APIs
- Backend handles authentication, business logic, and data persistence
- MongoDB stores user, course, and transaction data

---

## API Highlights

- `/api/auth/signup` – User registration
- `/api/auth/login` – Authentication with JWT
- `/api/courses` – Course CRUD operations
- `/api/courses/:id/rate` – Course ratings
- Secure role-based API access
